HTML QUIZ

1. Which HTML tag is used to define an internal style sheet?

  2. <css>
  3. <style>
  4. <link>

2. Which character is used to indicate an end tag in HTML?

  1. /
  2. *
  3. <
  4. ^

3. Which attribute provides alternative text for an image if it cannot be displayed?

  1. title
  2. src
  3. alt
  4. caption

4. What is the correct HTML tag for inserting a horizontal line?

  1. <line>
  2. <hr>
  3. <border>
  4. <break>

5. Which HTML tag is used to make text bold?

  1. <bold>
  2. <b>

  4. <heavy>

6. Which tag is used to define a standard table cell data element?

  3. <td>
  4. <tc>

7. How do you write a comment in HTML?

  1. // This is a comment
  2. <!-- This is a comment -->

8. Which element is used to define the title of a document displayed in the browser bar?

  1. <meta>
  2. <header>
  3. <title>
  4. <top>

9. Which attribute is used to open a link in a new tab or window?

  1. target="_blank"
